# Content Model

## Workflow status

Every structured collection uses `draft`, `review`, `approved`, or `archived`. Normal production listings show only approved entries.

## Collections

### Articles
Title, description, category, dates, author, status, featured flag, optional image and alt text, approval note, and Markdown body.

### Testimonials
Name or approved label, role, type, quote, workflow status, written-permission confirmation, and optional approved photograph.

### Leadership profiles
Name, verified role, approved summary, status, photograph, alt text, and verified achievements.

### Events
Title, location, year, approved summary, status, photograph, and alt text.

### Achievements
Title, year label, approved summary, status, and verification-required flag.

### Resources
Title, description, file path, workflow status, and direct-download behavior.

### Selected homepage content
A JSON file allows approved editors to update key headings and hero copy without changing layout code.
